# Editions

Each folder here is one IndieDuck edition: an exterior on the shared mechanism in `../platform/`. `cyber/` is IndieDuck Cyber Edition.

To submit a new edition, follow the guide in the project hub: [Submit an edition to IndieDuck](https://github.com/armature-ai-labs/indieduck/blob/main/SUBMIT-AN-EDITION.md). The rules every edition follows are in [../platform/PLATFORM.md](../platform/PLATFORM.md).
